アプリケーション名…推しごと

アプリケーションの概要 推しのスケジュールを一元管理できるアプリです。

開発した背景・想い 推し活に励む方たちに向け、推しのイベントやグッズ販売情報を一目でわかるようにし、見逃しをなくしたいと思ったため開発しました。
